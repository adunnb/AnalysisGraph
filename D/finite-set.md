**Definition:** For $n \in \mathbb{N}$, write $[n] = \{1, 2, \ldots, n\}$, and put $[0] = \varnothing$. A [set](../D/set) $A$ is **finite** if it has the same [cardinality](../D/cardinality) as $[n]$ for some $n \in \mathbb{N}_0$. This $n$ is the number of elements of $A$, written $\# A = n$. A set that is not finite is **infinite**.

**Example:** $\{a, b, c\}$ is finite with $\#\{a, b, c\} = 3$, and $\varnothing$ is finite with $\#\varnothing = 0$.

**Remark:** The notation $\# A$ only makes sense because $n$ is unique: a set cannot be in [bijection](../D/bijective) with both $[n]$ and $[m]$ for $n \neq m$ ([Uniqueness of finite cardinality](../T/finite-cardinality-unique)). A bijection $f : [n] \to A$ is the same thing as a list $A = \{f(1), \ldots, f(n)\}$ in which every element appears exactly once. The set $\mathbb{N}$ is infinite ([The natural numbers are infinite](../T/naturals-infinite)).
